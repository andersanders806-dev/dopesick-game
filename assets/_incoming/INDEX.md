# Incoming assets for the harbour and pro-feel work

A `.gdignore` file in this folder stops Godot importing any of it. Remove a file's folder from here (move it out) to import it.

Fetched 2026-10-28 on branch `assets-harbour`. Nothing here is wired into the game; everything is staged under `assets/_incoming/<category>/<asset>/`, each folder with a `SOURCE.md` (URL, author, licence, date). Move what you use into the real asset folders, run Godot's import, and add credits to `assets/LICENSES.md` (CC BY items need credit text; it is in each SOURCE.md).

Licence key: CC0 = no attribution needed. CC BY 4.0 = credit required (Sketchfab 'CC Attribution', Freesound 'Attribution'). No NC or ND items were taken. All sources are available in the EU.

## Sound groups: fit for purpose

- `sounds/waves_seawall/`: Waves on concrete/wall; loop-able long beds (24-90 s). Pick 384359 (CC0) as the base.
- `sounds/waves_piles/`: Water around piers/piles; 24-90 s.
- `sounds/harbour_night/`: Night harbour beds, 96-285 s. bruno.auzet 'working harbour by night' = good industrial night bed.
- `sounds/harbour_day/`: Day harbour; 24-93 s.
- `sounds/gulls/`: Gull calls, one-shots + longer beds.
- `sounds/foghorn/`: Foghorns; klankbeeld 611470 and digifishmusic 276570 are distant.
- `sounds/boat_engine_idle/`: Idle: kyles 451400 (fishing boat + rev at end), LG diesel boat loops 91533/91536 are short loops.
- `sounds/boat_engine_cut/`: GAP-ish: only 2 engine shut-offs found (craigsmith motor shutting off; boat slowing/stopping). A boat-specific 'engine cut then silence' may need layering with the idle loops.
- `sounds/boat_drift/`: Drifting hull creak/lap; rowing boat from inside is the nearest.
- `sounds/rope_creak/`: Mooring rope strain (Rmutt), generic creaks, boat rigging creak.
- `sounds/pier_footsteps_creak/`: Wood-dock walking, running, dock creaks. Footstep sets are continuous clips; slice per-step in an editor.
- `sounds/splash_fall_water/`: Body splash, jump in, cannonball off dock.
- `sounds/swimming/`: GAP: mostly pool swimming; no clean open-water cold swim strokes found. 191555 'sound of drowning' is useful for the go-under moment.
- `sounds/fishing_cast_reel_bite/`: Cast, reel, line/hook. GAP: no dedicated 'bite / bobber tug' sound found; use 'Fish approaching' / 'Hook and Release' plus a pitched rod-tip creak.
- `sounds/flashlight_click/`: On/off clicks.
- `sounds/room_tone_shop/`: Convenience-store interiors 40-175 s.
- `sounds/room_tone_bar/`: Bar without music (661686) and busy night bar 179 s.
- `sounds/room_tone_apartment/`: Quiet apartment room tones 20-110 s.
- `sounds/room_tone_jail/`: Prison ambience 70-92 s (contains voices, loop with care).
- `sounds/impact_hits/`: Punches, body hits, falls: hit-stop SFX layers (CC0 mostly).
- `sounds/glass_bottle_break/`: Bottle smashes 1-3 s.
- `sounds/cardboard_box_hit/`: Box strikes/rustle; 364932 has 13 strikes (slice).
- `sounds/shelf_crash_debris/`: No clean 'shelf crash' exists on Freesound under CC0/BY: wood crashes, clatters and debris to layer.

All sounds are Freesound's public high-quality previews (Ogg Vorbis, about 170 kbps, no login needed); lossless originals need a Freesound login. Quality is fine for in-game use, but not a mastering source. Per-file URL, author and licence are in each folder's SOURCE.md.

## Gaps and caveats

- **Water normal maps / foam**: generated procedurally (CC0, own work), not downloaded: none exist on Poly Haven / ambientCG, and the free web ones are AI-made or under custom licences. Seamless and scale-matched, but not photographic.
- **Seawall metal ladder**: only wooden ladders (Poly Haven) found. A rung ladder is simple to build from a cylinder plus `seawall/rusty_metal_02`.
- **Mooring bollard**: the only realistic one (rusty_ship_bollard) is a 29k-tri photoscan with baked albedo only; decimate for use. LDWO Mooring Bollard (71k tris) was skipped as too heavy.
- **Boat**: all three are CC BY; none is dark/black out of the box. Pick `boat/old_rusty_fishing_boat` (10k tris) and darken the albedo, or `fishing_ship_bialy` (22k) for a larger vessel. No outboard/RIB smuggling boat with a realistic finish was found under CC0/BY.
- **Duffel/holdall**: `bags/loot_bag` (dark, 10k tris) is the best fit; it shows cash in the opening. `military_duffel` is olive (re-tint). No big black CC0 duffel exists.
- **Lighthouse**: one realistic CC BY model; no CC0. It has no lamp/beam: add an emissive lantern room and a beam in-engine.
- **Pier piles**: no standalone pile model; the `modular_wooden_pier` pole mesh plus `pier/wood_planks_grey` / `green_rough_planks` PBR covers it. 84k tris whole, use sections.
- **Sounds missing**: no good 'engine cut' for a boat (2 weak candidates, layer with idle), no open-water swim strokes (pool swimming and a drowning clip instead), no dedicated fishing 'bite' cue, no genuine 'shelf crash' (use wood crash + clatter + debris layers). Footstep clips are continuous, slice per step.
- **Previews not originals**: Freesound login needed for lossless files; the API key route was not available.
- **Save icon**: Kenney Game Icons floppy is a flat glyph; fine as a base for the autosave indicator.
- **Fonts**: Barlow/Barlow Condensed (OFL) is recommended as the one UI family; Oswald (OFL) and Special Elite (Apache 2.0, typewriter, notebook only) are extras. Check Danish characters (aeoeaa) are present: they are in Barlow.
- **Kenney Input Prompts**: subset only (PlayStation Series, Keyboard & Mouse, Generic; Default PNG); Xbox/Switch/Steam/Double/Vector sets not kept.
- **Files over 50 MB**: none in the repo. The Sketchfab archives for `fishing_ship_bialy` (104 MB zip, 4k/8k textures), `old_rusty_fishing_boat` (67 MB zip) and `military_duffel` (63 MB zip) were above 50 MB as downloaded, so their textures were downscaled to 2048 px max; the files kept are all under 50 MB.
- **Credits**: CC BY items (all Sketchfab models, 24 Freesound clips) need entries in `assets/LICENSES.md` / title-screen credits when used. No NC/ND assets were taken.
- **Not tested in Godot**: nothing was imported or run (per instruction); glTF files with `KHR_materials_specular` / `specularf0` textures from Sketchfab may need a material tweak on import.

Re-fetch scripts used (kept outside the repo): Poly Haven API (`api.polyhaven.com`), Sketchfab Download API with the token in `~/.config/sketchfab/token`, Freesound search page previews, Kenney download-link endpoint, `google/fonts` on GitHub, and `sea/gen_sea.py`.
