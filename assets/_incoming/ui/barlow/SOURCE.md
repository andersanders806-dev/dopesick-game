# Barlow + Barlow Condensed (primary UI font family)

- URL: https://github.com/jpt/barlow ; fetched from https://github.com/google/fonts/tree/main/ofl/barlow and /barlowcondensed
- Author: Jeremy Tribby (The Barlow Project Authors)
- Licence: SIL Open Font License 1.1 (OFL.txt)
- Downloaded 2026-10-28
- Why: Slightly-rounded grotesk based on California highway/road signs; the Condensed cut is a hard, municipal, worn-signage look that suits a gritty city drama and stays legible at HUD sizes. Regular/Medium/SemiBold/Bold + Italic (Barlow). Use Condensed SemiBold/Bold for titles and HUD numbers, Barlow Regular/Medium for body and subtitles.
