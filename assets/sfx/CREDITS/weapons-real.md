# CREDITS - weapons, impacts, gore, handling

The shots of the pistol, magnum, SMG, AR, shotgun, sniper and LMG (the fire_<gun>_a/b/body/tail files listed here before SHIP 16 B1) are gone: each gun now has its own recorded set in assets/sfx/guns/<gun>/, credited in guns-recorded.md. What is left here is impacts, gore, handling and the arc caster.

All sources are from the **Sonniss GDC Game Audio Bundles** (https://sonniss.com/gameaudiogdc/), a royalty-free licence: commercial and non-commercial use in a game is allowed, no attribution required (credit given here anyway). Files were fetched individually from the Internet Archive mirrors of the bundles (items `sonniss-gdc-20NN-game-audio-bundle-normalized`). Raw source files are not redistributed; only the edited, layered game assets are.

Author = the contributing sound library named in the bundle folder (e.g. Pole Position Productions, Gamemaster Audio, SoundMorph, Sound Spark, 344 Audio, Justsoundeffects, Soundopolis, Shapeforms, Red Libraries, Super Thump, Sonic Bat, The Chris Alan, TS Sound, Stuart Duffield, Olivier Girardot).
