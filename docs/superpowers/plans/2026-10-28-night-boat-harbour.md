# The Sea, the Pier and the Night Boat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give story mode an RE4 over-the-shoulder camera, ring the block with open sea and a seawall, add one walkable pier, and the Night Boat story (fisherman Sal, fishing, the 3 AM drop, rip / tip / board ending).

**Architecture:** A shared camera rig `player/ShoulderCam.gd` replaces Player3D's fixed top-down TP mount (zombie Z5 builds on it). The sea, seawall and pier are generated by a new builder `dev-tools/city/harbour.gd` into `world/City3D.tscn` (new cell `Cell_Harbour`, sea + lighthouse in group `landmark`). The story is an autoload `autoload/Harbour.gd` (state, boat-night calendar, choices, save dict) driving NPCs in `npc/` and a fishing UI.

**Tech Stack:** Godot 4.7.2 (flatpak `org.godotengine.Godot`), GDScript static typing, Forward+ Vulkan; Rocketbox cast via `CharacterCast`.

**Spec:** `docs/superpowers/specs/2026-10-28-night-boat-harbour-design.md`

## Global Constraints

- Base: branch `harbour` off `zombie-mode` **after** open-world Tasks 2, 3, 4 are merged into it. Don't start before.
- Everything in the open-world plan's Global Constraints applies (`docs/superpowers/plans/2026-10-18-open-world-block.md`): headless test / window probe commands, regenerate scenes with `BuildRooms3D.tscn` and commit the regenerated `.tscn`, axes (x east, z south), floor layer 16, interactables layer 4, Main Street x in [-29, 29] untouched, perf on Low UHD 620: 60 FPS, GPU <= 13 ms, no frame > 25 ms while walking, City3D load <= 2.5 s, nothing loads or instantiates while walking.
- Tests per project convention: `_<feature>_checks(gs)` in `dev-tools/smoke_test_3d.gd`, called from `_run()`, plus `dev-tools/smoke_<feature>.gd`; full smoke must exit 0 at the end of every task.
- Walk/perf/render probes run with `-- --no-sick`; never change default gameplay for it.
- One pier only. Water is entered only from the pier (or by being thrown off it).
- Look: cold dirty city harbour at night — black-green water, low swell, lamp reflections, fog to the horizon. Never bright/cartoon.
- New assets: licence + author in `LICENSES.md` and credits; non-commercial OK, EU-excluded tools not.
- In zombie mode (Dead Block) sea and pier exist; Sal, fishing and boat nights don't.
- English in-game text, `##` why-comments like the existing files.

## Review Focus

1. Camera orbiting into the seawall corner / a narrow alley / a shop door — never inside geometry, never a frame of void → H1 test `camera_never_inside_geometry` sweeps yaw at fixed spots incl. alley x=14 and a block corner.
2. Saving mid-boat-night (bag stack out, crew on the pier, player under the boards or swimming) and loading → H4 test `boat_night_save_load`.
3. Player walks off the pier end at any time of day (not the rip) → H3 test `fall_off_pier_survivable`.
4. Boat night falls while the player is inside a shop or asleep at home → H4 test `boat_night_without_player` (drop still happens, nothing breaks, pusher returns).
5. Gamepad-only play: orbit, shoulder swap, fishing bite, hiding under the boards → each task's input checks use pad actions as well as keys (InputMap test, device -1).
